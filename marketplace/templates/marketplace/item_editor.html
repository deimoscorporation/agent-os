      Como funciona

      {% if kind == "agent" %}

      Um agente combina um modelo, instruções e as ferramentas do seu workspace. Só aparecem aqui as ferramentas instaladas — crie ou instale outras para ampliá-lo.

      {% elif kind == "skill" %}

      Uma skill é conhecimento reutilizável: instruções que um agente carrega quando precisa executar um tipo de tarefa. Pode ser usada como etapa de um workflow.

      {% else %}

      Um workflow encadeia ferramentas, agentes e skills do seu workspace em etapas executadas em ordem. Cada etapa recebe o resultado da anterior.

      {% endif %}
      {% if kind == "agent" %}

      No chat, o agente responde com as instruções e o modelo definidos aqui, usando a chave da OpenAI de quem conversa. As ferramentas ainda não são executadas: isso depende do ambiente isolado de execução.

      {% elif kind == "skill" %}

      A skill fica definida e instalável. Ela ainda não é carregada automaticamente pelos agentes.

      {% else %}

      O workflow fica definido e instalável. A execução das etapas ainda não está ativa.
